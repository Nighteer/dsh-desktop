# LETS Enterprise interface

This is an administration tool: stable left navigation, one primary creation action, readable identity/department/role/status tables and focused edit dialogs. The skill-generated marketing hero pattern is not applicable and is not adopted.

Use LETS branding, restrained green actions, neutral surfaces and system Chinese fonts. No external fonts or images are required. Admin stylesheet tokens are reused by the native login page.

Apply ui-ux-pro-max's web guidelines: explicit labels, password-manager/paste support, visible focus, semantic controls, text state labels, accessible dialogs, pending submit feedback, retained errors and responsive layouts.
