# LETS PPT runtime adaptation

Imported from `dataelement/dsh-desktop` commit
`bc732f5dc4c5465915d5b3f28d9b0b32703fc664` (2026-10-17 import).
The maintained JavaScript seeds and authored template generators are retained
under `packages/ppt-runtime/` and `scripts/`, with their original copyright,
MIT / Apache notices and template provenance. No withdrawn reference images
are restored. The upstream Harness submodule is not modified.

LETS adds the root-Yarn workspace wrapper, versioned build staging, current
Harness service compatibility, and desktop-owned compatibility slots. Windows
atomic publication retries transient file locks without deleting targets.
Generated templates and previews are ignored build output. Account storage is selected by
the enterprise desktop before this plugin starts; PPT data belongs to that
account's Harness home. The source credits do not imply endorsement or legal
clearance beyond the retained licenses.
